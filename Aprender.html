  1. DOCTYPE html

    2. Este comando es el inicio de todo documento html, es donde se integrara todo el codigo, y es el grupo que define que es html.

  2. html lang = "lenguaje"

    3. Aqui se define el lenguaje que tendra todo el codigo, asi para no tener erroes de codigo ni de palabras, dependiendo tambien de que lenguaje le tenga definido al visual studio code.

  3. HEAD

    4. En head, se podra todo lo que es definir la configuracion del codigo y el estilo que se le va a aplicar a este mismo.

  4. BODY

    5. Body es por asi decirlo la parte mas importante del codigo, ya que aqui contenido esta toodo el codigo visible y el que le da forma a todo el documento, tanto haciendo trabajo desde la consola o que sea visual desde la cara del documento como lo es este espacio.

  5. IMAGEN

    6. Asi como ven mi super imagen arriba, se mete a partir del codigo "img src="imagen" es basicamente la base de codigo para meter una imagen descargada en el dispositivo.

  6. TABLA

    7. Para la tabla se necesitan solo unos pocos comandos que son:

    • table: el contenedor de la tabla.
    • tr: fila(table row).
    • th: celda encabezadora.
    • td: celda de datos.
    • thead y tbody: agrupan encabezado y cuerpo (opcional pero recomendado).
